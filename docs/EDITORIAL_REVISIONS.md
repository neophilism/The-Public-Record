# TPR-13 — Evidence-aware editorial revision rules

**Status:** immutable-in-memory editorial projection and synthetic tests, not a deployed multi-editor CMS or a publication service.

Claims must be attributable and independently reviewed before publication. A public question is not automatically a verified accusation. Each public revision retains a visible evidence label: question, uncorroborated assertion, source-supported, agency-stated, document-confirmed, disputed or corrected.

Source-supported, official-agency and document-confirmed claims require citations. Disputed claims require contradictory sources. A reviewed correction must explicitly reference a previously published revision and explain the changed interpretation; the earlier statement remains visible in public history. Unreviewed drafts are not returned by the public projection. Editor notes and submitter contact details are excluded by explicit allowlist.

Withdrawal is a distinct state and must not invisibly rewrite earlier versions. Underlying source integrity, publication authorization, content moderation and secure archival/deletion work remain gated by the full 52-package plan.

**Operational completion still requires** durable per-investigation storage and editorial assignments, signed-in reviewer workflows, source-ID validation and hash-backed audit trails, corrections/takedown interfaces, accessible public displays, and tests using genuine contradictory evidence. No real person should be publicly accused or named through synthetic fixtures.
