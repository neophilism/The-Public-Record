# Redaction Gallery projection

The gallery accepts only genuine verified, already published release pages with a visible redaction. It links to the request and original public source. Editorial exemption notes are separate reviewed overlays; they are never written into or described as part of the agency's original document.

The image viewer, accessible zoom, source verification workflow and live public release feed are not wired yet. A privacy-reviewed derivative must be published through the separate consent gate before the gallery can receive a page.
