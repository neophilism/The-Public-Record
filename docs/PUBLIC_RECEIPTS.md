# Public Receipt card projection

A receipt card shows only supported dates and counts. Unknown page counts stay unknown. The verification label is ordinary text and requires a verified page count and agency receipt date. Public attribution defaults to anonymous; a displayed participant name or pseudonym requires an explicit publication choice. The QR payload is a stable canonical route that can resolve later corrections, not a static claim embedded in an image.

An accessible printable PDF, QR rendering, durable corrections and independently verified source records still need integration. This helper does not make a claim that a request was received merely because a participant entered a date.
