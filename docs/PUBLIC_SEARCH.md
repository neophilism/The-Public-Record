# Public search and truthful metrics

Only published rows enter this search projection; private rows do not affect results or counts. Pagination orders by publish timestamp and ID. Counts describe the published catalog only and make no claim about national FOIA coverage. Each result carries the date its source was reviewed for freshness display.

The authenticated data source, stable database cursor, agency/timeline filters, SEO pages and accessibility review remain to be implemented. Real queries must enforce publication policy at the database boundary in addition to this projection.
