# Walking Archive print boundary

Signs and placards display only reviewed public title, summary and a canonical HTTPS URL. A QR image must encode that current URL, so an outdated print can lead readers to subsequent corrections. A correction notice is printed when known. Private attribution is excluded from the asset.

The print/PDF layout, actual QR generation, mobile scanning test, black-and-white contrast test and accessible alternative text remain to be implemented. The safe payload model alone does not certify those physical outputs.
