# Evidence-focused Document Hunts

Each clue binds to a reviewed source ID, version, SHA-256 and HTTPS URL. Completion requires one verified navigation/answer for every clue. Duplicate visits, bad links and misattributed versions fail. The score has no filing, recruitment or request-volume input, so request spam cannot improve it.

The interactive trail, accessible clues, durable visit proof, abuse controls and reviewed public source catalog remain to be integrated. This domain scoring helper does not prove that a real browser visited a source until a trusted server records that event.
