# Missing Records Wall projection

The wall ranks documented gaps by evidence rank and links them to source pages. Counts distinguish verified missing records, hypothetical possibilities and resolved gaps. Hypothetical items must be labeled speculative in the page and never contribute to the verified missing count. A resolved gap retains its source and links to a published release.

The projector is ready for a reviewed public catalog, but no live catalog or filterable page is wired here. Editors must verify source evidence and status transitions before a live count is shown.
