# Correspondence and fee decisions

Agency letters, estimates, clarifications and referrals are private records linked to a request and a retained source digest. A user-supplied letter is unverified until an operator checks its provenance. The public projection intentionally includes only correspondence kind, agency component and review state.

An agency fee estimate does not authorize payment. The owner must make an explicit decision tied to that estimate, and an approval has a maximum amount in cents. An estimate above that cap produces no payable amount. This module models the decision boundary; authenticated private storage, official-source review, payment handling and agency-specific fee rules still require integration. No payment is attempted here.
