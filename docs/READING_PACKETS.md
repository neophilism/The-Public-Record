# Read the Record packet boundary

Reading packets retain exact source ID, version, SHA-256, page and URL for each reviewed excerpt. The print text includes that provenance next to the excerpt and context. Audio requires a transcript; video also requires captions. This enables an accessible source-first discussion without silently replacing an excerpt when its source page later changes.

The live excerpt reviewer, accessible page, printable PDF, optional gathering schedule and source-hash verification at publication remain to be implemented. Only approved public derivatives may enter packets; private originals and unreviewed extracted text cannot.
